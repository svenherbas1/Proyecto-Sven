Phishing | Malware | Ingeniería Social

¿Qué es el Phishing?

Es una técnica de suplantación digital donde el atacante se hace pasar por una entidad confiable para robar contraseñas, datos bancarios o información personal.

¿Qué es el Malware?

Es software malicioso que infecta dispositivos móviles con el objetivo de espiar, robar información o bloquear el sistema.

¿Qué es la Ingeniería Social?

Es una técnica basada en manipulación psicológica para engañar a una persona y obtener información confidencial o acceso a sistemas.

¿Cómo defenderse?

🛡 Verificar siempre la URL antes de ingresar datos.
🛡 Activar autenticación en dos pasos (2FA).
🛡 No instalar aplicaciones fuera de tiendas oficiales.
🛡 No compartir códigos de verificación.
🛡 Mantener el sistema operativo actualizado.
🛡 Desconfiar de premios o mensajes urgentes.
